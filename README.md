## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | AI 문제 출제·풀이 챗봇 (가칭) |
| 한 줄 소개 | 개념 자료를 바탕으로 AI가 문제를 만들고, 사용자 답을 채점한 뒤 풀이 위주로 해설하는 학습 챗봇 |
| 대상 사용자 | [과목]을 공부하는 학생 |
| 해결하려는 문제 | 기출은 양이 한정돼 있고 해설이 짧음 → 원하는 단원·난이도로 끝없이 연습하고 맞춤 해설을 받기 |
| 차별점 | ① RAG로 근거 자료 기반 출제
② 검증 AI로 정답 오류 걸러냄 
③ 오답 원인 분석 |

## 2. 기능 정의

| 구분 | 기능 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| 출제 | 단원·난이도 선택 출제 | 사용자가 단원과 난이도를 고르면 문제 생성 | 필수 |
| 출제 | 근거 기반 출제 (RAG) | 개념 자료에서 관련 내용을 검색해 문제의 근거로 사용 | 필수 |
| 출제 | 구조화 출력 | 문제, 보기, 정답, 해설, 근거를 JSON으로 생성 | 필수 |
| 검증 | 정답 교차 검증 | 별도 AI가 정답을 모르는 상태로 풀어서 출제 AI와 답이 다르면 재생성 | 필수 |
| 풀이 | 채점 | 사용자 답과 정답을 비교 | 필수 |
| 풀이 | 단계별 해설 | 정답에 이르는 과정을 단계별로 설명 | 필수 |
| 풀이 | 오답 분석 | 사용자가 고른 보기가 왜 틀렸는지 설명 | 필수 |
| 풀이 | 후속 질문 | "힌트만", "더 쉽게", "예시 더" 같은 멀티턴 대화 | 선택 |
| 학습관리 | 오답 기록 | 틀린 단원과 개념을 저장 | 선택 |
| 학습관리 | 약점 재출제 | 자주 틀린 개념으로 비슷한 문제 출제 (Agent) | 선택 |
| 부가 | 음성 해설 | 해설을 TTS로 읽어주기 | 선택 |

## 4. 시스템 흐름

| 단계 | 처리 | 입력 | 출력 |
| --- | --- | --- | --- |
| ① | 사용자 요청 | 단원, 난이도 | 출제 조건 |
| ② | 개념 검색 | 출제 조건 | 관련 개념 청크 (top-k) |
| ③ | 문제 생성 | 개념 청크 + 출제 프롬프트 | 문제 JSON |
| ④ | 검증 | 문제 (정답 제외) | 검증 AI의 답 → 출제 AI 답과 비교 |
| ⑤ | 출제 | 검증 통과한 문제 | 화면에 문제 표시 |
| ⑥ | 채점·해설 | 사용자 답 | 정오 판정, 단계별 해설, 오답 분석 |
| ⑦ | 기록 | 채점 결과 | 오답 노트 (선택) |

## 6. 위험 요소와 대응

| 위험 | 영향 | 대응 |
| --- | --- | --- |
